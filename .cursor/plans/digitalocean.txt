Balance API

  -H "Authorization: Bearer $DIGITALOCEAN_TOKEN" \

Retrieve an Invoice by UUID
/v2/customers/my/invoices/$INVOICE_UUID

curl -X GET \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $DIGITALOCEAN_TOKEN" \
  "https://api.digitalocean.com/v2/customers/my/invoices/$INVOICE_UUID


GET Retrieve an Invoice PDF by UUID
/v2/customers/my/invoices/$INVOICE_UUID/pdf

curl -X GET \
  -H "Content-Type: application/pdf" \
  -H "Authorization: Bearer $DIGITALOCEAN_TOKEN" \
  "https://api.digitalocean.com/v2/customers/my/invoices/$INVOICE_UUID/pdf" --output invoice.pdf
